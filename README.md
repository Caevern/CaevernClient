# Caevern Client
The fully opensource original Caevern client  
Custom 3d model importer? Of course,  
Custom server architecture? Of course,  
Custom packet system? Of course,  
Custom engine? Of course! :D  

# Compiling
You can compile the project using `cargo run` or `cargo build`.  
To run without vr, use the tag `--no-vr` (`cargo run - --no-vr`).  
To run with a custom server, use the tag `--server=ip:port` (`cargo run - --server=localhost:5000`).
